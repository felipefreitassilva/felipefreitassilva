    Juízes Rally - British Club

    • Before the app, synchronising the judges' stopwatches was its own event: everyone gathered beforehand to start them together, and a second of drift was a second of error in the results. Juizes Rally replaced that with one shared clock and one shared data model - up to ten judges and two to five organisers recording around thirty cars, working offline where the course has no signal and reconciling when it does. It has run the British Club's rally for three editions and is published on both the App Store and Google Play.
    • A companion web tool aggregates what the judges record as they record it, so organisers can watch the standings build instead of waiting for the paperwork, export the raw times to CSV, and generate the results deck the event closes with.
    • Technologies: React Native, Expo, TypeScript, Firebase, Git
