Accessibility

Many people do not have a choice in how they interact with the web. For some, keyboard‑only navigation is not a preference — it is a necessity.

Native HTML elements are accessible by default when used correctly. Overengineering often introduces barriers that make sites harder to use.

This portfolio keeps things simple and focused on usability.

Technology

HTML and CSS are the foundation of all web technologies. Frameworks and libraries build on and abstract these fundamentals.

Understanding and using native elements reduces unnecessary complexity. This choice improves maintainability and supports accessibility.

This site uses only the core web technologies — semantic HTML and CSS.

JavaScript is intentionally omitted here to emphasize native browser behavior and progressive enhancement.
